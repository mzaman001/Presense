## User flows (end to end, for the flow checks in each slice)

- **Sign-in:** `/login` (Google) → Supabase → `/auth/callback` → proxy session check → `(app)` layout → `/onboarding` if not complete. Slices 1, 5.
- **Onboarding:** `src/app/onboarding/*` → `user_settings` upsert → first plan → Home. Slices 5, 1.
- **Capture:** `C` / rail / share sheet / home-screen shortcut → `CaptureModal` → `capture-router` + NLP → `capture-outbox` (offline-safe) → `items` insert → realtime/cache refresh. Slices 3, 2, 1.
- **Do:** `/do` server render in saved timezone (`do/page.tsx`, `do-buckets`, `zoned-date`) → `TaskCard` (complete, swipe, edit via `TaskAddPanel`, snooze) → recurrence via `cron_recurrence`. Slices 3, 2, 1.
- **Focus:** Start on a task → `PomodoroTimer` (`focus-timer` persistence, chime) → `time_spent`/`pomodoro_count`. Slices 3, 2.
- **Rituals:** morning/evening due (`rituals.ts`) → `RitualOverlay` (sweep, plan, capacity) → `last_ritual_date`. Slices 4, 2.
- **Reminders:** Task "Remind me" / ritual times → `push_reminders` cron + Edge Function → Web Push → `sw.ts` → `/do?remind=` → `ReminderSheet`. Slices 1, 5, 3.
- **Settings:** `SettingsModal` (autosave, theme, timezone auto, notifications, data export/delete account) → `user_settings`. Slices 4, 1.
- **Think / Remember / Inbox / Search / Trash:** list views, thread page, locations, search modal, soft delete + `cron_cleanup`. Slices 4, 3, 1.
- **Offline / PWA:** service worker precache, `/~offline`, outbox replay (`CaptureSync`), update prompt. Slices 5, 2.
- **Sign-out / account deletion:** push unsubscribe, session clear, data removal. Slices 1, 4.
