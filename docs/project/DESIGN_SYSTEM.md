# Superseded

This file documented glass surfaces, ambient background orbs, and four independently-hued per-space colors. That direction is being replaced, not iterated on: the current design authority is [`docs/superpowers/specs/2026-09-13-design-system-overhaul-design.md`](../superpowers/specs/2026-09-13-design-system-overhaul-design.md), which specifies flat surfaces (no glass/glow), one accent color, and a light="sunrise"/dark="sunset" palette — the opposite of several rules this file stated as settled.

The source of truth for how to work in this repo is [`AGENTS.md`](../../AGENTS.md). For the current design direction, read the spec linked above, not this file.

This file can be deleted once the overhaul spec's tokens land in `globals.css` and this file's content is fully superseded in practice, not just in writing.
